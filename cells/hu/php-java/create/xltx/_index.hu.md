1.  Telepítse a „Aspose.Cells for PHP via Java” fájlt.
1.  Adj hozzá egy könyvtárhivatkozást (importáld a könyvtárat) a PHP projektedhez.
1.  Hozz létre egy példányt a következőből:[Munkafüzet](https://reference.aspose.com/cells/php/aspose.cells/Workbook) osztály.
1.  megfelelő munkalapot a getWorksheets.get() metódussal érheted el.
1.  Jelölje ki a kívánt cellát, és írja be az értéket a kívánt cellába a cella nevének használatával, például A1, B3 stb.
1.  Mentsd el a munkafüzetet XLTX formátumban a save() metódussal.

{{% blocks/products/pf/agp/code-block title="A mintakód bemutatja, hogyan hozható létre a XLTX fájl PHP-ben." offSpacer="" %}}

```python

require_once("Java.inc");
require_once("lib/aspose.cells.php");

use aspose\cells;
use aspose\cells\Workbook;


$workbook = new Workbook();
$sheets = $workbook->getWorksheets();
$cells = $sheets->get(0)->getCells();

// Add relevant content in the cell
$cells->get("A1")->putValue("ColumnA");
$cells->get("B1")->putValue("ColumnB");
$cells->get("A2")->putValue("ValueA");
$cells->get("B2")->putValue("ValueB");


// Save the workbook as XLTX file
$workbook->save("Excel.xltx"); 

```
