Basato sullo standard Open XML (ECMA-376), un file XLSX è un archivio ZIP contenente una raccolta di parti XML che descrivono fogli di lavoro, stili, grafici e altri elementi della cartella di lavoro. Aspose.Cells funziona direttamente con questo formato, consentendo la generazione e la manipolazione ad alte prestazioni di file Excel su qualsiasi piattaforma.
