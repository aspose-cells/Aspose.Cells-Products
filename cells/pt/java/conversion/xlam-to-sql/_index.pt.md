Os arquivos XLAM são arquivos baseados em XML semelhantes aos formatos de arquivo XLSM e XLSX e são salvos com compactação ZIP para reduzir o tamanho geral do arquivo.{{< /blocks/products/pf/agp/i18n/about-file-text >}}

Arquivos SQL são comuns ao trabalhar com bancos de dados de desktop e também baseados na Web. Existem várias alternativas ao SQL como Java Persistence Query Language (JPQL), LINQ, HTSQL, 4D QL e várias outras.
