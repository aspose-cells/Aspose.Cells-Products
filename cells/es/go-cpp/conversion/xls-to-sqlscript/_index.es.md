Cada línea de un archivo XLS representa un nuevo registro del conjunto de registros que contiene. Estos archivos se generan al transferir datos de un sistema de almacenamiento a otro. Dado que todas las aplicaciones reconocen registros separados por comas, la importación de estos archivos de datos a la base de datos es muy sencilla. Casi todas las aplicaciones de hojas de cálculo, como Excel Microsoft u OpenOffice Calc, pueden importar XLS sin mayor esfuerzo. Esta independencia permite abrir el archivo en múltiples plataformas, como Microsoft, Windows y Mac.
