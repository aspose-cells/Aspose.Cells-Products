{{% /blocks/products/pf/agp/text %}}

1.  Instal 'Aspose.Cells for PHP via Java'.
1.  Tambahkan referensi pustaka (impor pustaka) ke proyek PHP Anda.
1.  Buat sebuah instance dari[Buku Kerja](https://reference.aspose.com/cells/php/aspose.cells/Workbook) kelas.
1. Akses lembar kerja yang relevan menggunakan metode getWorksheets.get().
1.  Pilih sel yang relevan, masukkan nilai ke dalam sel yang diinginkan menggunakan nama sel, seperti A1, B3, dan seterusnya.
1.  Simpan buku kerja dalam format XLSB menggunakan metode save().

{{% blocks/products/pf/agp/code-block title="Contoh kode menunjukkan cara membuat file XLSB di PHP." offSpacer="" %}}

```python

require_once("Java.inc");
require_once("lib/aspose.cells.php");

use aspose\cells;
use aspose\cells\Workbook;


$workbook = new Workbook();
$sheets = $workbook->getWorksheets();
$cells = $sheets->get(0)->getCells();

// Add relevant content in the cell
$cells->get("A1")->putValue("ColumnA");
$cells->get("B1")->putValue("ColumnB");
$cells->get("A2")->putValue("ValueA");
$cells->get("B2")->putValue("ValueB");


// Save the workbook as XLSB file
$workbook->save("Excel.xlsb"); 

```
