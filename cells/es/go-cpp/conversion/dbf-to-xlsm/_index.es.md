        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="DBF" readMoreLink="" >}}Los archivos con la extensión "dbf" representan archivos de texto sin formato que contienen registros de datos separados por comas. Cada línea de un archivo DBF representa un nuevo registro del conjunto de registros que contiene. Estos archivos se generan al transferir datos de un sistema de almacenamiento a otro. Dado que todas las aplicaciones reconocen registros separados por comas, la importación de estos archivos de datos a la base de datos es muy sencilla. Casi todas las aplicaciones de hojas de cálculo, como Excel u OpenOffice Calc, pueden importar archivos DBF sin mayor esfuerzo. Estas imágenes son independientes del adaptador gráfico y también se denominan formato de archivo de mapa de bits independiente del dispositivo (DIB). Esta independencia permite abrir el archivo en múltiples plataformas, como Microsoft, Windows y Mac.
