        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="TSV" readMoreLink="https://docs.fileformat.com/spreadsheet/tsv/" >}}Dateien mit der Endung „tsv“ sind einfache Textdateien, die Datensätze mit durch Kommas getrennten Werten enthalten. Jede Zeile in einer TSV-Datei stellt einen neuen Datensatz aus der in der Datei enthaltenen Datenmenge dar. Solche Dateien werden erstellt, wenn Daten von einem Speichersystem auf ein anderes übertragen werden sollen. Da alle Anwendungen durch Kommas getrennte Datensätze erkennen können, ist der Import solcher Datendateien in eine Datenbank sehr einfach. Nahezu alle Tabellenkalkulationsprogramme wie Excel oder OpenOffice Calc können TSV-Dateien problemlos importieren. Die aus solchen Dateien importierten Daten werden zur Darstellung für den Benutzer in den Zellen einer Tabellenkalkulation angeordnet.{{< /blocks/products/pf/agp/i18n/about-file-text >}}

Diese Bilder sind unabhängig von der Grafikkarte und werden daher auch als geräteunabhängiges Bitmap-Dateiformat (DIB) bezeichnet. Diese Unabhängigkeit ermöglicht das Öffnen der Datei auf verschiedenen Plattformen wie Windows und macOS.
