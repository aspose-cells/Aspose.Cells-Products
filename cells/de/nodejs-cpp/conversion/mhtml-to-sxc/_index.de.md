MHTML-Dateien können in einer Vielzahl von Anwendungen wie Internet Explorer und Microsoft Word geöffnet werden. Microsoft Windows verwendet das Dateiformat MHTML zum Aufzeichnen von Problemszenarien, die während der Verwendung einer beliebigen Anwendung auf Windows beobachtet wurden und Probleme verursachen.
