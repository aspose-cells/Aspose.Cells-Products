Файлы XLAM представляют собой файлы на основе XML, аналогичные форматам файлов XLSM и XLSX, и сохраняются с сжатием ZIP для уменьшения общего размера файла.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
