        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="Ots" readMoreLink="" >}}Les fichiers avec l'extension « ots » sont des fichiers texte brut contenant des enregistrements de données dont les valeurs sont séparées par des virgules. Chaque ligne d'un fichier .ots correspond à un nouvel enregistrement parmi ceux contenus dans le fichier. Ces fichiers sont générés lors du transfert de données d'un système de stockage à un autre. Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Presque tous les tableurs, tels qu'Excel ou OpenOffice Calc, peuvent importer des fichiers .ots sans difficulté. Les données importées sont ensuite organisées dans les cellules d'une feuille de calcul pour être présentées à l'utilisateur.{{< /blocks/products/pf/agp/i18n/about-file-text >}}

Ces images sont indépendantes de la carte graphique et sont également appelées fichiers bitmap indépendants du périphérique (DIB). Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs portables et Mac. Le format de fichier .ods peut stocker des données sous forme d'images numériques bidimensionnelles, monochromes ou couleur, avec différentes profondeurs de couleur.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
