Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs portables et Mac.
