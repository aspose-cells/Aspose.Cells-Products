Le format XLSX est le format de fichier par défaut des classeurs Excel (Microsoft), introduit avec Office 2007. Il respecte les conventions OPC (Open Packaging Conventions) et stocke les données, les styles et les objets incorporés du classeur sous forme de fichiers XML dans une archive ZIP. Le format Aspose.Cells est compatible avec ce format et ne nécessite pas l'installation d'Office (Microsoft).
