Die folgenden Schritte zeigen, wie man ein Donut-Diagramm in ein Arbeitsblatt einfügt:

1.  Fügen Sie den Namespace Aspose.Cells hinzu.
2. Erstellen Sie eine Instanz mit der ID `Workbook`.
3. Öffnen Sie das Zielarbeitsblatt.
4. Füllen Sie die Zellen des Arbeitsblatts mit den Daten, die das Diagramm verwenden soll.
5. Fügen Sie eine `Chart` vom Typ `ChartType.Doughnut` hinzu.
6. Definieren Sie den Datenbereich für die Diagrammreihe.
7. Optionale Formatierung anwenden (Titel, Farben, Legende).
8. Speichern Sie die Arbeitsmappe.
