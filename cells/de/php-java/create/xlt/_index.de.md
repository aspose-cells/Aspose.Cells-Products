{{% blocks/products/pf/agp/text %}}

 Für Entwickler ist es einfach, mit nur wenigen Codezeilen XLT-Dateien in verschiedenen laufenden Berichtsanwendungen zur Datenverarbeitung zu erstellen, zu laden, zu ändern und zu konvertieren.

{{% /blocks/products/pf/agp/text %}}

1.  Installieren Sie „Aspose.Cells for PHP via Java“.
1.  Fügen Sie Ihrem PHP-Projekt einen Bibliotheksverweis hinzu (importieren Sie die Bibliothek).
1.  Erstellen Sie eine Instanz von[Arbeitsmappe](https://reference.aspose.com/cells/php/aspose.cells/Workbook) Klasse.
1. Das entsprechende Arbeitsblatt kann mit der Methode getWorksheets.get() aufgerufen werden.
1.  Wählen Sie die entsprechende Zelle aus und geben Sie den Wert in die gewünschte Zelle ein, indem Sie den Zellennamen verwenden, z. B. A1, B3 usw.
1.  Speichern Sie die Arbeitsmappe im Format XLT mit der Methode save().

{{% blocks/products/pf/agp/code-block title="Der Beispielcode zeigt, wie man die Datei XLT in PHP erstellt." offSpacer="" %}}

```python

require_once("Java.inc");
require_once("lib/aspose.cells.php");

use aspose\cells;
use aspose\cells\Workbook;


$workbook = new Workbook();
$sheets = $workbook->getWorksheets();
$cells = $sheets->get(0)->getCells();

// Add relevant content in the cell
$cells->get("A1")->putValue("ColumnA");
$cells->get("B1")->putValue("ColumnB");
$cells->get("A2")->putValue("ValueA");
$cells->get("B2")->putValue("ValueB");


// Save the workbook as XLT file
$workbook->save("Excel.xlt"); 

```
