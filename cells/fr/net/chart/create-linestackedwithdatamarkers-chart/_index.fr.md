Le format XLSX est le format de classeur par défaut pour Excel (Microsoft). Basé sur la norme Open XML (ECMA-376), un fichier XLSX est une archive ZIP contenant un ensemble de fragments XML décrivant les feuilles de calcul, les styles, les graphiques et autres éléments du classeur. Excel (Aspose.Cells) fonctionne directement avec ce format, permettant ainsi la génération et la manipulation performantes de fichiers Excel sur n'importe quelle plateforme.
