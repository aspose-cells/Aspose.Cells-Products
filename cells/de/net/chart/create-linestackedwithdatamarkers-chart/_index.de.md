XLSX ist das Standard-Arbeitsmappenformat für Excel (Microsoft). Basierend auf dem Open-XML-Standard (ECMA-376) ist eine Datei im Format XLSX ein ZIP-Archiv, das eine Sammlung von XML-Teilen enthält, welche Arbeitsblätter, Formatvorlagen, Diagramme und andere Arbeitsmappenelemente beschreiben. Aspose.Cells ist direkt mit diesem Format kompatibel und ermöglicht so die leistungsstarke Erstellung und Bearbeitung von Excel-Dateien auf jeder Plattform.
