1.  Installer**Aspose.Cells** via NuGet (`Install-Package Aspose.Cells`).
2. Ajoutez la directive `using Aspose.Cells;`.
3. Créez une instance `Workbook`.
4. Remplissez une feuille de calcul avec des données.
5. Ajouter un `Chart` de type `ChartType.DoughnutExploded`.
6. Définissez la plage de données pour la série du graphique.
7. (Facultatif) Définissez un titre au graphique et appliquez un style intégré.
8. Enregistrez le classeur.
