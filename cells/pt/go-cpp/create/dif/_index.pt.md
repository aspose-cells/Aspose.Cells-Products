 É fácil para os desenvolvedores criar, carregar, modificar e converter arquivos DIF em aplicativos de relatórios em execução para processamento de dados em apenas algumas linhas de código.

{{% /blocks/products/pf/agp/text %}}

1.  Crie um objeto da classe Workbook.
1.  Coloque a primeira planilha em um objeto Worksheet.
1.  Use o método Worksheet.GetCells() para colocar as células da planilha em um objeto Cells.
1.  Use o método Cells.Get() para acessar a célula desejada da planilha em um objeto Cell.
1.  Use o método Cell.PutValue() para inserir o valor na célula.
1. Salve a planilha como um arquivo .bmp usando o método Save().

{{% blocks/products/pf/agp/code-block title="O código de exemplo mostra como criar o arquivo DIF em Go através do arquivo C++." offSpacer="" %}}

```go

	workbook, _ := NewWorkbook()
	worksheets, _ := workbook.GetWorksheets()
	worksheet, _ := worksheets.Get_Int(0)
	cells, _ := worksheet.GetCells()
	cell, _ := cells.Get_String("A1")
	cell.PutValue_String("Hello World!")
	cell, _ = cells.Get_String("A2")
	cell.PutValue_Int(15)
	cell, _ = cells.Get_String("A3")
	cell.PutValue_Int(25)
	workbook.Save_String("HelloWorld.dif")

```
