Chaque ligne d'un fichier SXC correspond à un nouvel enregistrement parmi ceux contenus dans le fichier. Ces fichiers sont générés lors du transfert de données d'un système de stockage à un autre. Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Presque tous les tableurs, tels qu'Excel ou OpenOffice Calc, peuvent importer ces fichiers SXC sans difficulté. Ces images sont indépendantes de la carte graphique et sont également appelées fichiers bitmap indépendants du périphérique (DIB). Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs et macOS.
