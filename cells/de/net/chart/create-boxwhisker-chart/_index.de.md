Die Schritte sind einfach:

1. Füge den Namespace Aspose.Cells hinzu.
2. Erstellen Sie eine Instanz mit der ID `Workbook`.
3. Füllen Sie ein Arbeitsblatt mit den Quelldaten.
4. Fügen Sie ein Diagramm ein und stellen Sie dessen Typ auf `ChartType.BoxWhisker` ein.
5. Binden Sie das Diagramm an den Datenbereich.
6. (Optional) Diagrammtitel, -stil und -achse anpassen.
7. Speichern Sie die Arbeitsmappe.
