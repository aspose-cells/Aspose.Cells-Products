 biblioteca Aspose.Cells para JavaScript, via C++, é uma biblioteca de alto desempenho e rica em recursos para manipulação e conversão de planilhas, incluindo os formatos Excel (XLS, XLSX, XLSB, XLSM), ODS, CSV e HTML.
