1.  Nainstalujte 'Aspose.Cells for PHP via Java'.
1.  Přidejte do svého PHP projektu odkaz na knihovnu (importujte knihovnu).
1.  Vytvořte instanci[pracovní sešit](https://reference.aspose.com/cells/php/aspose.cells/Workbook) třída.

{{% blocks/products/pf/agp/code-block title="Ukázkový kód ukazuje, jak vytvořit MD soubor v PHP." offSpacer="" %}}

```python

require_once("Java.inc");
require_once("lib/aspose.cells.php");

use aspose\cells;
use aspose\cells\Workbook;


$workbook = new Workbook();
$sheets = $workbook->getWorksheets();
$cells = $sheets->get(0)->getCells();

// Add relevant content in the cell
$cells->get("A1")->putValue("ColumnA");
$cells->get("B1")->putValue("ColumnB");
$cells->get("A2")->putValue("ValueA");
$cells->get("B2")->putValue("ValueB");


// Save the workbook as MD file
$workbook->save("Excel.md"); 

```
