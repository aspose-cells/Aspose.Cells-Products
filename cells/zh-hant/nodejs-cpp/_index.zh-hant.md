<p>
 Aspose.Cells、for Node.js 和 C++ 是功能豐富且可擴展的 API，用於使用 Node.js 處理 Excel 電子表格。 API 提供 Excel 檔案格式轉換、精細化的工作表樣式設定、圖表建立和渲染、可靠的公式計算引擎等等。
</p>

<p>
Aspose.Cells for Node.js 透過 C++ 支援大多數流行的電子表格格式，包括 XLS、XLSX、ODS、SpreadsheetML、CSV153481、SpreadsheetML、CSV61538348111、CSV1。
</p>
