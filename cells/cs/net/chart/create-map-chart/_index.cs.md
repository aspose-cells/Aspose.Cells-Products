Následující kroky ukazují, jak přidat mapový graf do listu:

 2. Vytvořte instanci `Workbook`.
 3. Vyplňte pracovní list geografickými údaji (např. názvy zemí a jejich hodnotami).
 4. Vložte graf typu *Mapa**.
 5. Propojte datovou řadu s geografickým rozsahem.
