Les étapes suivantes vous guident tout au long du processus de création d'un graphique Surface3D par programmation :

2. Créez une instance `Workbook`.
3. Remplissez une feuille de calcul avec les données qui seront tracées sur la surface.
4. Insérez un graphique de type *Surface3D**.
5. Configurez le titre du graphique, les axes et la mise en forme facultative.
6. Enregistrez le classeur.
