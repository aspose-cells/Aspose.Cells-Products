**Fasi tipiche**

1. Includere lo spazio dei nomi richiesto.
2. Creare un'istanza `Workbook`.
3. Popolare le celle del foglio di lavoro con dati campione.
4. Aggiungere un grafico di tipo `ChartType.Column` (il grafico di base).
5. Convertire il grafico in un grafico combinato.
 6. Aggiungi un*Colonna* serie e una*Linea* serie.
7. Impostare l'asse secondario per la serie Line (facoltativo).
8. Salvare la cartella di lavoro come file XLSX.
