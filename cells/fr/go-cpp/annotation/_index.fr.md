{{% blocks/products/pf/feature-page-section h2="Annotations de données dans les fichiers Excel" %}}
 Gestion des commentaires dans les feuilles de calcul - Le nombre de commentaires dans une feuille Excel est illimité. Vous pouvez en insérer autant que nécessaire. La procédure d'insertion des commentaires consiste à créer[Cahier d'exercices](https://reference.aspose.com/cells/go-cpp/aspose.cells/workbook/) Utilisez un objet de classe pour charger un fichier existant et sélectionner la feuille de calcul dans laquelle vous souhaitez ajouter le commentaire. Récupérez tous les commentaires à l'aide de la méthode `getComments()`. Ajoutez le commentaire en utilisant…[Ajouter(const char16_t* nom_cellule)](https://reference.aspose.com/cells/go-cpp/aspose.cells/commentcollection/add/) méthode. Obtenez l'index de la cellule et utilisez[SetNote](https://reference.aspose.com/cells/go-cpp/aspose.cells/comment/setnote/) pour insérer des commentaires. De plus, API permet de supprimer tous les commentaires. Voici quelques méthodes :[ClearComments()](https://reference.aspose.com/cells/go-cpp/aspose.cells/worksheet/clearcomments/) Efface tous les commentaires dans la feuille de calcul du concepteur. De plus,***SupprimerÀ*** Méthode permettant de supprimer l'élément à un index spécifié ou avec un nom spécifié.
