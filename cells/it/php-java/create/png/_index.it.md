{{% blocks/products/pf/agp/text %}}

 È facile per gli sviluppatori creare, caricare, modificare e convertire i file PNG eseguendo diverse applicazioni di reporting per l'elaborazione dei dati in poche righe di codice.

{{% /blocks/products/pf/agp/text %}}

1.  Installa 'Aspose.Cells for PHP via Java'.
1.  Aggiungi un riferimento alla libreria (importa la libreria) al tuo progetto PHP.
1.  Crea un'istanza di[Cartella di lavoro](https://reference.aspose.com/cells/php/aspose.cells/Workbook) classe.
1. Accedere al foglio di lavoro pertinente utilizzando il metodo getWorksheets.get().
1.  Selezionare la cella pertinente, immettere il valore nella cella desiderata utilizzando il nome della cella, ad esempio A1, B3, ecc.
1.  Salvare la cartella di lavoro nel formato PNG utilizzando il metodo save().

{{% blocks/products/pf/agp/code-block title="Il codice di esempio mostra come creare il file PNG in PHP." offSpacer="" %}}

```python

require_once("Java.inc");
require_once("lib/aspose.cells.php");

use aspose\cells;
use aspose\cells\Workbook;


$workbook = new Workbook();
$sheets = $workbook->getWorksheets();
$cells = $sheets->get(0)->getCells();

// Add relevant content in the cell
$cells->get("A1")->putValue("ColumnA");
$cells->get("B1")->putValue("ColumnB");
$cells->get("A2")->putValue("ValueA");
$cells->get("B2")->putValue("ValueB");


// Save the workbook as PNG file
$workbook->save("Excel.png"); 

```
