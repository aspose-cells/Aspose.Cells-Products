 2. Créez une instance de**Cahier d'exercices** classe.
 3. Accédez à la feuille de calcul qui contiendra les données et le graphique.
 4. Remplissez les cellules avec les séries de données que le graphique utilisera.
 5. Insérez un objet graphique et définissez ses**Type de graphique** à *ChartType.PyramidBar**.
 6. Définissez la plage de données pour la série du graphique.
 7. Appliquer un style de graphique prédéfini (facultatif).
8. Enregistrez le classeur en tant que**XLSX** déposer.
