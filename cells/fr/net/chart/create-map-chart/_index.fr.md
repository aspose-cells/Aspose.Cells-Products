Les étapes suivantes montrent comment ajouter un graphique de type carte à une feuille de calcul :

1.  Incluez l'espace de noms `Aspose.Cells`.
 2. Créez une instance `Workbook`.
 3. Remplissez la feuille de calcul avec des données géographiques (par exemple, les noms et valeurs des pays).
 4. Insérez un graphique de type *Carte**.
 5. Associer les séries de données à la zone géographique.
 6. Configurer les propriétés du graphique (titre, style de couleur, etc.).
7. Enregistrez le classeur sous le nom de fichier XLSX.
