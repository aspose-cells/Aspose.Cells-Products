Jede Zeile einer Epub-Datei stellt einen neuen Datensatz dar. Solche Dateien werden erstellt, wenn Daten von einem Speichersystem auf ein anderes übertragen werden sollen. Da alle Anwendungen durch Kommas getrennte Datensätze erkennen können, ist der Import solcher Dateien in eine Datenbank sehr einfach. Fast alle Tabellenkalkulationsprogramme wie Excel oder OpenOffice Calc können Epub-Dateien problemlos importieren. Diese Bilder sind unabhängig von der Grafikkarte und werden daher auch als geräteunabhängiges Bitmap-Dateiformat (DIB) bezeichnet. Diese Unabhängigkeit ermöglicht das Öffnen der Datei auf verschiedenen Plattformen wie Windows (Microsoft), macOS (Windows) und Windows (JSON).
