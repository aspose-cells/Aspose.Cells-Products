        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="Epub" readMoreLink="" >}}Les fichiers avec l'extension « epub » sont des fichiers texte brut contenant des enregistrements de données dont les valeurs sont séparées par des virgules. Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Presque tous les tableurs, tels qu'Excel ou OpenOffice Calc, peuvent importer des fichiers epub sans difficulté. Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs portables et Mac.
