<p>
 Aspose.Cells for Node.js přes C++ je funkčně bohatý a škálovatelný nástroj API pro zpracování excelových tabulek pomocí Node.js. API nabízí konverzi formátů souborů Excel, stylování pracovních listů na nejjemnější úrovni, vytváření a vykreslování grafů, spolehlivý výpočetní modul vzorců a mnoho dalšího.
</p>

<p>
Aspose.Cells for Node.js přes C++ podporuje nejoblíbenější formáty tabulek včetně XLS, XLSX, ODS, SpreadsheetML, CSV, TSC a HTML.
</p>
