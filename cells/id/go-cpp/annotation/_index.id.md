{{% blocks/products/pf/feature-page-section h2="Anotasi Data File Excel" %}}
 Memanipulasi Komentar di Lembar Kerja - Tidak ada batasan jumlah komentar dalam sebuah lembar kerja di MS Excel. Kita dapat menyisipkan komentar sebanyak yang dibutuhkan aplikasi. Proses penyisipan komentar adalah, membuat[Buku Kerja](https://reference.aspose.com/cells/go-cpp/aspose.cells/workbook/) Objek kelas untuk memuat file yang sudah ada dan memilih lembar kerja tempat Anda ingin menambahkan komentar. Dapatkan semua komentarnya menggunakan getComments(). Tambahkan komentar menggunakan[Tambahkan(konstanta char16_t* cellName)](https://reference.aspose.com/cells/go-cpp/aspose.cells/commentcollection/add/) metode. Dapatkan indeks sel dan gunakan[SetNote](https://reference.aspose.com/cells/go-cpp/aspose.cells/comment/setnote/) untuk memasukkan komentar. Selain itu, API mampu menghapus semua komentar. Beberapa metodenya adalah[ClearComments()](https://reference.aspose.com/cells/go-cpp/aspose.cells/worksheet/clearcomments/) Menghapus semua komentar di spreadsheet perancang. Selain itu,***HapusDi*** Metode untuk menghapus elemen pada indeks tertentu atau dengan nama tertentu.
