Un gráfico cónico (también conocido como gráfico piramidal) es útil para visualizar datos donde el ancho de cada elemento representa un valor. Los siguientes pasos muestran cómo agregar un gráfico cónico a una hoja de cálculo.

{{% /blocks/products/pf/agp/text %}}

1.  Incluya el espacio de nombres Aspose.Cells en su archivo de clase.
 2. Crea una instancia del**Libro de trabajo** clase.
 3. Acceda a la hoja de trabajo donde se colocará el gráfico.
 4. Complete la hoja de trabajo con datos de muestra.
 5. Agregar un**Cuadro** objeto de tipo *ChartType.Cone**.
 6. Establezca la posición y el tamaño del gráfico.
 7. Vincula el gráfico al rango de datos.
 8. Aplicar formato opcional (título, leyenda, estilo).
9. Guarde el libro de trabajo.
