**Langkah-langkah umum**

1. Sertakan namespace yang dibutuhkan.
2. Buat instance `Workbook`.
3. Isi sel-sel lembar kerja dengan data contoh.
4. Tambahkan bagan tipe `ChartType.Column` (bagan dasar).
5. Ubah grafik menjadi grafik kombinasi.
 6. Tambahkan*Kolom* seri dan sebuah*Garis* seri.
7. Atur sumbu sekunder untuk seri Garis (opsional).
8. Simpan buku kerja sebagai file XLSX.
