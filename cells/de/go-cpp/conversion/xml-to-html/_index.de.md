Jede Zeile einer XML-Datei stellt einen neuen Datensatz dar. Solche Dateien werden erstellt, wenn Daten von einem Speichersystem auf ein anderes übertragen werden sollen. Da alle Anwendungen durch Kommas getrennte Datensätze erkennen können, ist der Import solcher Datendateien in eine Datenbank sehr einfach. Nahezu alle Tabellenkalkulationsprogramme wie Excel oder OpenOffice Calc können XML-Dateien problemlos importieren.
