Os passos são simples:

1. Adicione o namespace Aspose.Cells.
2. Crie uma instância `Workbook`.
3. Preencha uma planilha com os dados de origem.
4. Insira um gráfico e defina seu tipo como `ChartType.BoxWhisker`.
5. Vincule o gráfico ao intervalo de dados.
6. (Opcional) Personalize o título, o estilo e os eixos do gráfico.
7. Salve a planilha.
