 Es fácil para los desarrolladores crear, cargar, modificar y convertir archivos SQL dentro de aplicaciones de informes en ejecución para el procesamiento de datos en solo unas pocas líneas de código.

1.  Crea un objeto de la clase Workbook.
1.  Obtenga la primera hoja en un objeto Hoja de trabajo.
1.  Utilice el método Worksheet.getCells() para obtener las celdas de la hoja de cálculo en un objeto Cells.
1.  Utilice el método Cells.get() para acceder a la celda deseada de la hoja de cálculo en un objeto Cell.
1.  Utilice el método Cell.putValue() para ingresar un valor en la celda.
1.  Guarde el libro de trabajo como archivo .sql usando el método Save().

{{% blocks/products/pf/agp/code-block title="El código de muestra muestra cómo crear un archivo SQL en Node.js." offSpacer="" %}}

```cs
const AsposeCells = require("aspose.cells.node");

// Create an object of the Workbook class.
var wkb = new AsposeCells.Workbook();
// Get the first sheet into an Worksheet object.
var wsc = wkb.getWorksheets();
var ws = wsc.get(0);

// Use Worksheet.getCells() method to get the cells of the worksheet into an Cells object.
var cells = ws.getCells();


// Use Cells.Get() method to access the desired cell of the worksheet into an Cell object.
var cell00 = cells.get(0, 0);
var cell01 = cells.get(0, 1);
var cell10 = cells.get(1, 0);
var cell11 = cells.get(1, 1);


// Use Cell.PutValue() method to input value into the cell.
cell00.putValue("ColumnA");
cell01.putValue("ColumnB");
cell10.putValue("ValueA");
cell11.putValue("ValueB");


// Save workbook to resultFile folder
wkb.save("created_one.sql");

```
