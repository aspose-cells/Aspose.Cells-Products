Il respecte les conventions d'emballage ouvertes (OPC) et stocke les données, les styles et les graphiques du classeur dans un ensemble de fichiers XML compressés dans une archive ZIP. Le logiciel Aspose.Cells prend entièrement en charge la lecture et l'écriture de ce format, y compris tous les types de graphiques.
