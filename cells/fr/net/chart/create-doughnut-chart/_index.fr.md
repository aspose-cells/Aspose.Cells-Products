Les étapes suivantes montrent comment ajouter un graphique en anneau à une feuille de calcul :

1.  Incluez l'espace de noms Aspose.Cells.
2. Créez une instance `Workbook`.
3. Accédez à la feuille de calcul cible.
4. Remplissez les cellules de la feuille de calcul avec les données que le graphique utilisera.
5. Ajouter un `Chart` de type `ChartType.Doughnut`.
6. Définissez la plage de données pour la série du graphique.
7. Appliquer la mise en forme facultative (titre, couleurs, légende).
8. Enregistrez le classeur.
