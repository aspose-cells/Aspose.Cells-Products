Da alle Anwendungen durch Kommas getrennte Datensätze erkennen, ist der Import solcher Dateien in Datenbanken sehr einfach. Diese Unabhängigkeit ermöglicht das Öffnen der Datei auf verschiedenen Plattformen wie z. B. Windows und macOS.
