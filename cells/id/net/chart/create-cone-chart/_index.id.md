Bagan kerucut (juga dikenal sebagai bagan piramida) berguna untuk memvisualisasikan data di mana lebar setiap item mewakili suatu nilai. Langkah-langkah berikut menunjukkan cara menambahkan bagan kerucut ke lembar kerja.

{{% /blocks/products/pf/agp/text %}}

1.  Sertakan namespace Aspose.Cells di dalam file kelas Anda.
 2. Buat sebuah instance dari**Buku Kerja** kelas.
 3. Akses lembar kerja tempat grafik akan ditempatkan.
 4. Isi lembar kerja dengan data sampel.
 5. Tambahkan**Bagan** objek bertipe *ChartType.Cone**.
 6. Atur posisi dan ukuran grafik.
 7. Kaitkan grafik dengan rentang data.
 8. Terapkan pemformatan opsional (judul, keterangan, gaya).
9. Simpan buku kerja.
