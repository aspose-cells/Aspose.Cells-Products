        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}Les fichiers avec l'extension « csv » sont des fichiers texte brut contenant des enregistrements de données dont les valeurs sont séparées par des virgules. Chaque ligne d'un fichier CSV correspond à un nouvel enregistrement parmi ceux contenus dans le fichier. Ces fichiers sont générés lors du transfert de données d'un système de stockage à un autre. Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Presque tous les tableurs, tels qu'Excel ou OpenOffice Calc, peuvent importer ces fichiers CSV sans difficulté. Les données importées sont ensuite organisées dans les cellules d'une feuille de calcul pour être présentées à l'utilisateur.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="TIFF" readMoreLink="https://docs.fileformat.com/image/tiff/" >}}Les fichiers avec l'extension .tiff sont des fichiers image bitmap utilisés pour stocker des images numériques bitmap. Ces images sont indépendantes de la carte graphique et sont également appelées fichiers bitmap indépendants du périphérique (DIB). Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs et macOS. Le format de fichier .tiff peut stocker des données sous forme d'images numériques bidimensionnelles, monochromes ou couleur, avec différentes profondeurs de couleur.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
