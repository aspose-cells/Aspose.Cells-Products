<p>
Pustaka Aspose.Cells Go via C++ adalah alat yang ampuh untuk manipulasi spreadsheet yang dapat dimanfaatkan dari aplikasi Go via C++ melalui Cgo. Dengan pustaka ini, Anda dapat melakukan berbagai operasi spreadsheet, seperti membuat, mengkonversi, dan mengedit Properti Bawaan dan Kustom, menerapkan Tema, Gaya, dan Pemformatan, mengelola Validasi Data, menerapkan Pemformatan Bersyarat, dan menjalankan berbagai fungsi, termasuk Membaca, Menulis, dan Menghitung Rumus. Fitur-fitur canggih seperti Pengelompokan Baris dan Kolom juga didukung, semuanya tanpa perlu Otomasi Office atau ketergantungan pada Excel Microsoft. Versi API kompatibel dengan format spreadsheet yang paling umum, termasuk XLS, XLSX, XLSM, dan XLSB, dan juga mendukung berbagai jenis file lain seperti PDF dan XPS, bersama dengan format gambar populer seperti JPEG, PNG, BMP, TIFF, GIF, EMF, dan SVG.
</p>
