Como todos os aplicativos conseguem reconhecer registros separados por vírgula, a importação desses arquivos de dados para um banco de dados é feita de forma muito conveniente. Quase todos os aplicativos de planilha, como o Excel ou o OpenOffice Calc, conseguem importar arquivos DBF sem muita dificuldade.
