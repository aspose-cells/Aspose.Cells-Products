Da alle Anwendungen durch Kommas getrennte Datensätze erkennen, lassen sich diese Dateien sehr einfach in Datenbanken importieren. Diese Unabhängigkeit ermöglicht das Öffnen der Datei auf verschiedenen Plattformen wie Windows (Microsoft), macOS (Windows) und Windows (PDF).
