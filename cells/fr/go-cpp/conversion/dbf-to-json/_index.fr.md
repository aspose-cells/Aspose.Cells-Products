        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="DBF" readMoreLink="" >}}Les fichiers avec l'extension « .dbf » sont des fichiers texte brut contenant des enregistrements de données dont les valeurs sont séparées par des virgules. Chaque ligne d'un fichier DBF correspond à un nouvel enregistrement. Ces fichiers sont générés lors du transfert de données d'un système de stockage à un autre. Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Presque tous les tableurs, tels qu'Excel ou OpenOffice Calc, peuvent importer des fichiers DBF sans difficulté. Les données importées sont ensuite organisées dans les cellules d'une feuille de calcul pour être présentées à l'utilisateur.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="JSON" readMoreLink="https://docs.fileformat.com/web/json/" >}}Les fichiers avec l'extension .json sont des fichiers image bitmap utilisés pour stocker des images numériques bitmap. Ces images sont indépendantes de la carte graphique et sont également appelées fichiers bitmap indépendants du périphérique (DIB). Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs portables et Mac. Le format de fichier .json peut stocker des données sous forme d'images numériques bidimensionnelles, monochromes ou en couleur avec différentes profondeurs de couleur.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
