{{% /blocks/products/pf/agp/text %}}

1.  Instalar**Aspose.Cells** vía NuGet (`Install-Package Aspose.Cells`).
2. Agregue la directiva `using Aspose.Cells;`.
3. Cree una instancia `Workbook`.
4. Llene una hoja de cálculo con datos.
5. Agregue un `Chart` del tipo `ChartType.DoughnutExploded`.
6. Defina el rango de datos para la serie del gráfico.
7. (Opcional) Establezca un título para el gráfico y aplique un estilo incorporado.
8. Guarde el libro de trabajo.
