{{% /blocks/products/pf/agp/text %}}

1.  Instalar**Aspose.Cells** via NuGet (`Install-Package Aspose.Cells`).
2. Adicione a diretiva `using Aspose.Cells;`.
3. Crie uma instância `Workbook`.
4. Preencha uma planilha com dados.
5. Adicione um `Chart` do tipo `ChartType.DoughnutExploded`.
6. Defina o intervalo de dados para a série do gráfico.
7. (Opcional) Defina um título para o gráfico e aplique um estilo integrado.
8. Salve a planilha.
