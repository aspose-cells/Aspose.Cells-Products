Das Format SXC unterstützt Formeln, Funktionen, Makros und Diagramme sowie DataPilot, eine unglaubliche Funktion, da es importierte Rohdaten automatisch individualisiert und Zusammenfassungen bereitstellt. Das Format ist als Teil der von OASIS veröffentlichten und gepflegten ODF 1.2-Spezifikationen angegeben. Eine Reihe von Anwendungen auf Windows sowie anderen Betriebssystemen können ODS-Dateien zum Bearbeiten und Manipulieren öffnen, darunter Microsoft Excel, NeoOffice und LibreOffice.
