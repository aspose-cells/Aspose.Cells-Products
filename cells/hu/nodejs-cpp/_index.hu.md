<p>
 A Aspose.Cells for Node.js via C++ egy funkciókban gazdag és skálázható API, amely Excel-táblázatok Node.js használatával történő feldolgozására szolgál. A API Excel-fájlformátum-konvertálást, a munkalapok legrészletesebb szintű formázását, diagramok létrehozását és renderelését, megbízható képletszámító motort és még sok mást kínál.
</p>

<p>
 Aspose.Cells for Node.js a C++-es számon keresztül támogatja a legnépszerűbb táblázatkezelő formátumokat, beleértve a XLS, XLSX, ODS, SpreadsheetML, CSV, TSC és HTML szabványokat.
</p>
