Les étapes sont simples :

1. Ajoutez l'espace de noms Aspose.Cells.
2. Créez une instance `Workbook`.
3. Remplissez une feuille de calcul avec les données sources.
4. Insérez un graphique et définissez son type sur `ChartType.BoxWhisker`.
5. Liez le graphique à la plage de données.
6. (Facultatif) Personnalisez le titre, le style et l'axe du graphique.
7. Enregistrez le classeur.
