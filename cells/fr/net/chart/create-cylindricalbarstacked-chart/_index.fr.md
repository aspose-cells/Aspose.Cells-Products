Les étapes suivantes montrent comment ajouter un graphique à barres cylindriques empilées à un classeur :

1. Incluez l'espace de noms Aspose.Cells.
2. Créez une instance `Workbook`.
3. Accédez à une feuille de calcul et remplissez-la avec des exemples de données.
4. Ajouter un graphique de type `ChartType.CylindricalBarStacked`.
5. Définissez la plage de la source de données du graphique.
6. Appliquer un style prédéfini (facultatif).
7. Enregistrez le classeur sous le nom de fichier XLSX.

XLSX est le format de fichier par défaut pour les classeurs Excel introduits avec Office 2007. Il est basé sur la norme Open XML (ECMA‑376) et stocke les données sous forme d'une collection de parties XML dans un conteneur ZIP, permettant un stockage efficace et un accès facile au contenu du classeur.
