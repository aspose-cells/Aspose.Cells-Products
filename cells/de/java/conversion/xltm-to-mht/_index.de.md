Es kann Daten wie Text, Bilder, Seitenstyling in Form von CSS-Dateien, JavaScript und andere Ressourcen als eingebettete Ressourcen darin speichern. MHT-Dateien mit dem MIME-Typ message/rfc822 kapseln den gesamten Inhalt einer HTML-Datei als einzelne Archivdatei zur Speicherung auf Archivierungsgeräten. Mit Softwareanwendungen wie Microsoft Word können Sie Ihre WORD-Dokumente in MHT konvertieren, indem Sie sie als MHT-Datei exportieren.
