Os passos a seguir mostram como adicionar um gráfico de rosca a uma planilha:

1.  Inclua o namespace Aspose.Cells.
2. Crie uma instância `Workbook`.
3. Acesse a planilha desejada.
4. Preencha as células da planilha com os dados que o gráfico utilizará.
5. Adicione um `Chart` do tipo `ChartType.Doughnut`.
6. Defina o intervalo de dados para a série do gráfico.
7. Aplique a formatação opcional (título, cores, legenda).
8. Salve a planilha.
