XLSX é o formato de pasta de trabalho padrão para o Excel Microsoft. Baseado no padrão Open XML (ECMA-376), um arquivo XLSX é um arquivo ZIP que contém uma coleção de partes XML que descrevem planilhas, estilos, gráficos e outros elementos da pasta de trabalho. O formato Aspose.Cells funciona diretamente com esse formato, permitindo a geração e manipulação de arquivos Excel com alto desempenho em qualquer plataforma.
