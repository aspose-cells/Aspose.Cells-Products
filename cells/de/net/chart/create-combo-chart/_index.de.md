**Typische Schritte**

1. Fügen Sie den erforderlichen Namespace hinzu.
2. Erstellen Sie eine Instanz mit der ID `Workbook`.
3. Füllen Sie die Zellen des Arbeitsblatts mit Beispieldaten.
4. Fügen Sie ein Diagramm vom Typ `ChartType.Column` (das Basisdiagramm) hinzu.
5. Konvertieren Sie das Diagramm in ein Kombinationsdiagramm.
 6. Füge ein*Spalte* Serie und ein*Linie* Serie.
7. Legen Sie die sekundäre Achse für die Linienreihe fest (optional).
8. Speichern Sie die Arbeitsmappe als XLSX-Datei.
