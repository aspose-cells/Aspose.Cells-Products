Comme toutes les applications reconnaissent les enregistrements séparés par des virgules, l'importation de ces fichiers de données dans une base de données est très simple. Presque tous les tableurs, tels qu'Excel ou OpenOffice Calc, peuvent importer ces fichiers TXT sans difficulté. Cette indépendance permet d'ouvrir le fichier sur plusieurs plateformes, telles que les ordinateurs et macOS.
