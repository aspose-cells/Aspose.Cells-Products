1.  Schließen Sie den Namespace in Ihre Klassendatei ein
1.  Erstellen Sie eine Instanz der Workbook-Klasse.
1.  Greifen Sie auf das erste Arbeitsblatt der Arbeitsmappe zu.
1. Holen Sie sich die gewünschte(n) Zelle(n) des Arbeitsblatts und geben Sie den Wert in die Zelle(n) ein.
1.  Verwenden Sie die Methode „Speichern“, um die Arbeitsmappe als Datei MARKDOWN zu speichern.

{{% blocks/products/pf/agp/code-block title="Der Beispielcode zeigt, wie die Datei MARKDOWN in C# erstellt wird." offSpacer="" %}}

```cs

// Create Workbook class instance.
Workbook wkb = new Workbook();

// Access the first worksheet of the workbook.
Worksheet sht = wkb.Worksheets[0];

// Get the desired cell(s) of the worksheet.
Cell c00 = sht.Cells["A1"];
Cell c01 = sht.Cells["B1"];
Cell c10 = sht.Cells["A2"];
Cell c11 = sht.Cells["B2"];

// input the value into the cell(s).
c00.PutValue("ColumnA");
c01.PutValue("ColumnB");
c10.PutValue("ValueA");
c11.PutValue("ValueB");

// Save the Workbook as .md file.
wkb.Save("created_one.md");

```
