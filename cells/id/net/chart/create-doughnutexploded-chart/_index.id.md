{{% /blocks/products/pf/agp/text %}}

1.  Install**Aspose.Cells** melalui NuGet (`Install-Package Aspose.Cells`).
2. Tambahkan arahan `using Aspose.Cells;`.
3. Buat instance `Workbook`.
4. Isilah lembar kerja dengan data.
5. Tambahkan `Chart` dengan tipe `ChartType.DoughnutExploded`.
6. Tentukan rentang data untuk rangkaian grafik.
7. (Opsional) Tetapkan judul grafik dan terapkan gaya bawaan.
8. Simpan buku kerja.
