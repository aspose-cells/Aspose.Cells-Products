De onderstaande stappen tonen de minimale code die nodig is om een DoughnutExploded-grafiek te genereren. Het voorbeeld is volledig uitvoerbaar en vereist niet dat Excel (versie Microsoft) op de server is geïnstalleerd.

{{% /blocks/products/pf/agp/text %}}

1.  Installeren**Aspose.Cells** via NuGet (`Install-Package Aspose.Cells`).
2. Voeg de richtlijn `using Aspose.Cells;` toe.
3. Maak een instantie met de status `Workbook` aan.
4. Vul een werkblad in met gegevens.
5. Voeg een `Chart` van type `ChartType.DoughnutExploded` toe.
6. Definieer het gegevensbereik voor de grafiekreeks.
7. (Optioneel) Stel een grafiektitel in en pas een ingebouwde stijl toe.
8. Sla het werkblad op.
