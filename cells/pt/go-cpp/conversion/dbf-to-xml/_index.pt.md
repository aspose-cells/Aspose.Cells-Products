        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="DBF" readMoreLink="" >}}Arquivos com extensão "dbf" representam arquivos de texto simples que contêm registros de dados com valores separados por vírgula. Cada linha em um arquivo DBF é um novo registro do conjunto de registros contidos no arquivo. Esses arquivos são gerados quando se pretende transferir dados de um sistema de armazenamento para outro. Como todos os aplicativos conseguem reconhecer registros separados por vírgula, a importação desses arquivos de dados para um banco de dados é feita de forma muito conveniente. Quase todos os aplicativos de planilha, como o Excel ou o OpenOffice Calc, conseguem importar arquivos DBF sem muita dificuldade. Os dados importados desses arquivos são organizados em células de uma planilha para serem exibidos ao usuário.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="Xml" readMoreLink="" >}}Arquivos com extensão .xml representam arquivos de imagem bitmap, usados para armazenar imagens digitais bitmap. Essas imagens são independentes da placa de vídeo e também são chamadas de formato de arquivo bitmap independente de dispositivo (DIB). Essa independência permite abrir o arquivo em diversas plataformas, como Windows e Mac. O formato de arquivo XML pode armazenar dados como imagens digitais bidimensionais, tanto em formato monocromático quanto colorido, com diferentes profundidades de cor.{{< /blocks/products/pf/agp/i18n/about-file-text >}}
