Cada linha em um arquivo XML é um novo registro do conjunto de registros contidos no arquivo. Esses arquivos são gerados quando se pretende transferir dados de um sistema de armazenamento para outro. Como todos os aplicativos conseguem reconhecer registros separados por vírgula, a importação desses arquivos de dados para um banco de dados é feita de forma muito conveniente. Quase todos os aplicativos de planilha, como o Excel ou o OpenOffice Calc, conseguem importar arquivos XML sem muita dificuldade.
