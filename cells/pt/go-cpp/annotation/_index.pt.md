 Manipulando comentários em planilhas - Não há limite para a quantidade de comentários que uma planilha pode conter no MS Excel. É possível inserir quantos comentários forem necessários. O processo de inserção de comentários consiste em criar um novo comentário.[Pasta de trabalho](https://reference.aspose.com/cells/go-cpp/aspose.cells/workbook/) Utilize um objeto de classe para carregar um arquivo existente e selecione a planilha onde deseja adicionar o comentário. Adicione o comentário usando[Adicionar(const char16_t* cellName)](https://reference.aspose.com/cells/go-cpp/aspose.cells/commentcollection/add/) método. Obtenha o índice da célula e use[Nota de configuração](https://reference.aspose.com/cells/go-cpp/aspose.cells/comment/setnote/) para inserir comentários. Além disso, API é capaz de remover todos os comentários. Alguns dos métodos são[ClearComments()](https://reference.aspose.com/cells/go-cpp/aspose.cells/worksheet/clearcomments/) Limpa todos os comentários na planilha do designer.
