 3. Remplissez la feuille de calcul avec les données sources du graphique.
 4. Ajouter un**Graphique** objet de type *ChartType.Funnel**.
 5. Définissez la position, la taille et la plage de données du graphique.
 6. Appliquer la mise en forme facultative (titre, style, étiquettes de données).
7. Enregistrez le classeur dans un fichier XLSX.
