 การใช้แผนภูมิใน Excel ช่วยให้มองเห็นภาพรวมและวิเคราะห์ข้อมูลได้ง่ายขึ้น เพื่อการตัดสินใจที่ถูกต้อง[ไปที่หมายเลข C++ ในไลบรารี Excel](/cells/th/go-cpp/) รองรับการสร้างแผนภูมิที่แตกต่างกันโดยแสดงรายการต่างๆ[enum Aspose::Cells::Charts::ChartType
](https://reference.aspose.com/cells/go-cpp/charttype/) รวมถึงแผนภูมิพื้นที่ แผนภูมิแท่ง แผนภูมิวงกลม แผนภูมิพีระมิด แผนภูมิเส้น และแผนภูมิฟอง นอกจากนี้ สำหรับการแปลงแผนภูมิเป็นรูปภาพ หมายเลข API ยังมีบริการอีกด้วย[ถึงรูปภาพ](https://reference.aspose.com/cells/go-cpp/chart/toimage_string/) แปลงวิธีการให้เป็นรูปแบบภาพที่ต้องการ
