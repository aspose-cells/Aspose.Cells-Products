<p>
La biblioteca Aspose.Cells Go vía C++ es una potente herramienta para la manipulación de hojas de cálculo que se puede aprovechar desde aplicaciones Go vía C++ mediante Cgo. Con esta biblioteca, puede realizar una amplia gama de operaciones en hojas de cálculo, como crear, convertir y editar propiedades integradas y personalizadas, aplicar temas, estilos y formato, gestionar la validación de datos, implementar formato condicional y ejecutar diversas funciones, como leer, escribir y calcular fórmulas. También se admiten funciones avanzadas como agrupar filas y columnas, todo ello sin necesidad de automatización de oficina ni dependencia de Microsoft Excel. El API es compatible con los formatos de hojas de cálculo más comunes, incluidos XLS, XLSX, XLSM y XLSB, y también admite varios otros tipos de archivos como PDF y XPS, junto con formatos de imagen populares como JPEG, PNG, BMP, TIFF, GIF, EMF y SVG.
</p>
