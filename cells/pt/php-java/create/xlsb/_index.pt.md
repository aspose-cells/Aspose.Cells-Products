{{% /blocks/products/pf/agp/text %}}

1.  Instale 'Aspose.Cells for PHP via Java'.
1.  Adicione uma referência à biblioteca (importe a biblioteca) ao seu projeto PHP.
1.  Crie uma instância de[Pasta de trabalho](https://reference.aspose.com/cells/php/aspose.cells/Workbook) aula.
1. Acesse a planilha relevante usando o método getWorksheets.get().
1.  Selecione a célula relevante e insira o valor na célula desejada usando o nome da célula, como A1, B3, etc.
1.  Salve a planilha no formato XLSB usando o método save().

{{% blocks/products/pf/agp/code-block title="O código de exemplo mostra como criar o arquivo XLSB em PHP." offSpacer="" %}}

```python

require_once("Java.inc");
require_once("lib/aspose.cells.php");

use aspose\cells;
use aspose\cells\Workbook;


$workbook = new Workbook();
$sheets = $workbook->getWorksheets();
$cells = $sheets->get(0)->getCells();

// Add relevant content in the cell
$cells->get("A1")->putValue("ColumnA");
$cells->get("B1")->putValue("ColumnB");
$cells->get("A2")->putValue("ValueA");
$cells->get("B2")->putValue("ValueB");


// Save the workbook as XLSB file
$workbook->save("Excel.xlsb"); 

```
