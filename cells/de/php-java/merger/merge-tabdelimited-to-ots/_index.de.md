Jeder Datensatz in einer TSV-Datei ist in einer einzelnen Textzeile enthalten, in der jeder Feldwert durch ein Tabulatorzeichen getrennt ist. Die Anwendungssoftware Calc ähnelt Excel, das in Microsoft Office verfügbar ist. Das OTS-Dateiformat wird zum Erstellen von Vorlagen verwendet, die vordefinierte Einstellungen in Bezug auf Stile, Schriftart, Daten, Tabellenlayout und Formatierung enthalten. OTF-Dateien haben den MIME-Typ application/vnd.oasis.opendocument.spreadsheet-template.
