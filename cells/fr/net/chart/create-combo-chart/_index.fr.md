**Étapes typiques**

1. Incluez l'espace de noms requis.
2. Créez une instance `Workbook`.
3. Remplissez les cellules de la feuille de calcul avec des exemples de données.
4. Ajouter un graphique de type `ChartType.Column` (le graphique de base).
5. Convertissez le graphique en un graphique combiné.
 6. Ajouter un*Colonne* série et une*Doubler* série.
7. Définissez l'axe secondaire pour la série de lignes (facultatif).
8. Enregistrez le classeur sous le nom de fichier XLSX.
