Un graphique à barres coniques (également appelé graphique à barres en entonnoir) met visuellement en évidence la taille relative des séries de données. Vous trouverez ci-dessous les étapes nécessaires à la création d'un tel graphique à l'aide de Aspose.Cells.

{{% /blocks/products/pf/agp/text %}}

1.  Incluez l'espace de noms `Aspose.Cells` dans votre fichier source.
 2. Créez une instance `Workbook`.
 3. Remplissez une feuille de calcul avec les données que vous souhaitez visualiser.
 4. Ajoutez un graphique à la feuille de calcul et définissez son type sur *ConicalBar**.
 5. Configurez la série, les titres des axes et le titre du graphique.
6. Enregistrez le classeur sous le nom de fichier XLSX.

Le format XLSX est le format de fichier Excel moderne introduit avec Office 2007. Il s'agit d'une archive ZIP contenant un ensemble de parties XML définies par les normes Open XML ECMA-376 / ISO/IEC 29500. Le logiciel Aspose.Cells lit et écrit ce format nativement, offrant ainsi une fidélité et des performances élevées.
