Le format XLSX (ou Microsoft) est le format de fichier par défaut d'Excel, introduit avec Office 2007. Il respecte les conventions OPC (Open Packaging Conventions) et stocke les données, les styles et les graphiques du classeur sous forme de fichiers XML dans une archive ZIP. Le logiciel Aspose.Cells est compatible avec ce format, ce qui vous permet de générer et de modifier des fichiers XLSX sur n'importe quelle plateforme.
