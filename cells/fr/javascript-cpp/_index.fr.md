<p>
La bibliothèque JavaScript Aspose.Cells (via C++) est une bibliothèque performante et riche en fonctionnalités permettant de manipuler et de convertir des fichiers tableur, notamment aux formats Excel (XLS, XLSX, XLSB, XLSM, ODS, CSV et HTML). Elle offre un ensemble complet de fonctionnalités pour la création, l'édition, la conversion et l'affichage de feuilles de calcul dans les environnements navigateur et Node.js. Grâce à sa compatibilité totale avec tous les principaux formats Excel, la bibliothèque JavaScript Aspose.Cells (via C++) garantit une compatibilité et une flexibilité maximales pour une grande variété de cas d'utilisation.
</p>
<p>
Conçu avec WebAssembly pour offrir des performances quasi natives directement dans le navigateur, le composant JavaScript Aspose.Cells (via C++) permet un traitement rapide et efficace des feuilles de calcul sans serveur. Sa légèreté le rend idéal pour les applications web sans serveur nécessitant des fonctionnalités Excel avancées. Que vous développiez des tableaux de bord, des pipelines de traitement de données ou des outils de génération de documents, le composant JavaScript Aspose.Cells (via C++) constitue une solution complète, fiable et performante, parfaitement compatible avec les environnements web, serveur et hybrides.
</p>

        async function openSave(saveFormat, extension) {
            const fileInput = document.getElementById('fileInput');
            if (!fileInput.files.length) {

            }

            const file = fileInput.files[0];
            const arrayBuffer = await file.arrayBuffer();
            var workbook = new Workbook(new Uint8Array(arrayBuffer));
            const outputData = workbook.save(saveFormat);

            const blob = new Blob([outputData]);
