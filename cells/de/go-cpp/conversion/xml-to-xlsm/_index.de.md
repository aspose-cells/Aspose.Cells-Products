        {{< blocks/products/pf/agp/i18n/about-file-text fileFormat="Xml" readMoreLink="" >}}Dateien mit der Endung „.xml“ sind einfache Textdateien, die Datensätze mit durch Kommas getrennten Werten enthalten. Jede Zeile einer XML-Datei stellt einen neuen Datensatz dar. Solche Dateien werden erstellt, wenn Daten von einem Speichersystem auf ein anderes übertragen werden sollen. Da alle Anwendungen durch Kommas getrennte Datensätze erkennen können, ist der Import solcher Datendateien in eine Datenbank sehr einfach. Nahezu alle Tabellenkalkulationsprogramme wie Excel oder OpenOffice Calc können XML-Dateien problemlos importieren. Die importierten Daten werden in den Zellen einer Tabellenkalkulation angeordnet und dem Benutzer angezeigt.{{< /blocks/products/pf/agp/i18n/about-file-text >}}

Diese Bilder sind unabhängig von der Grafikkarte und werden daher auch als geräteunabhängiges Bitmap-Dateiformat (DIB) bezeichnet. Diese Unabhängigkeit ermöglicht das Öffnen der Datei auf verschiedenen Plattformen wie z. B. Windows Microsoft, Windows Windows und macOS.
