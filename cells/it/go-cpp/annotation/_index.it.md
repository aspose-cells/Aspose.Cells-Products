{{% blocks/products/pf/feature-page-section h2="Annotazioni dei dati dei file Excel" %}}
 Manipolazione dei commenti nei fogli di lavoro: in MS Excel, il numero di commenti presenti in un foglio non è limitato. È possibile inserirne quanti ne richiede l'applicazione. Il processo di inserimento dei commenti è: creare[Cartella di lavoro](https://reference.aspose.com/cells/go-cpp/aspose.cells/workbook/) oggetto classe per caricare un file esistente e selezionare il foglio di lavoro in cui si desidera aggiungere il commento. Ottenere tutti i suoi commenti utilizzando getComments(). Aggiungere il commento utilizzando[Aggiungi(const char16_t* nomecella)](https://reference.aspose.com/cells/go-cpp/aspose.cells/commentcollection/add/) metodo. Ottieni l'indice della cella e usa[Imposta nota](https://reference.aspose.com/cells/go-cpp/aspose.cells/comment/setnote/) per l'inserimento di commenti. Inoltre, API è in grado di rimuovere tutti i commenti. Pochi dei metodi sono[ClearComments()](https://reference.aspose.com/cells/go-cpp/aspose.cells/worksheet/clearcomments/) per cancellare tutti i commenti nel foglio di calcolo del progettista. Inoltre,***RimuoviAt*** metodo per rimuovere l'elemento in un indice specificato o con il nome specificato.
