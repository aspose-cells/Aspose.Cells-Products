{{% blocks/products/pf/feature-page-section h2="Anotaciones de datos de archivos de Excel" %}}
 Manipulación de comentarios en hojas de cálculo: No hay límite en la cantidad de comentarios que puede tener una hoja en MS Excel. Se pueden insertar tantos como la aplicación necesite. El proceso para insertar comentarios es crear...[Libro de trabajo](https://reference.aspose.com/cells/go-cpp/aspose.cells/workbook/) Objeto de clase para cargar un archivo existente y seleccionar la hoja de cálculo donde se desea agregar el comentario. Obtenga todos sus comentarios usando getComments(). Agregue el comentario usando[Agregar(const char16_t* nombreCelda)](https://reference.aspose.com/cells/go-cpp/aspose.cells/commentcollection/add/) método. Obtenga el índice de la celda y úselo[Establecer nota](https://reference.aspose.com/cells/go-cpp/aspose.cells/comment/setnote/) para insertar comentarios. Además, API puede eliminar todos los comentarios. Algunos de los métodos son...[ClearComments()](https://reference.aspose.com/cells/go-cpp/aspose.cells/worksheet/clearcomments/) Borra todos los comentarios en la hoja de cálculo del diseñador. Además,***Quitar en*** método para eliminar el elemento en un índice especificado o con un nombre especificado.
